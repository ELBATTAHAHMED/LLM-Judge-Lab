The final source-corrected analysis is governed by the following fixed policy: source precedence is SOURCE\_CORRECT\_REUSABLE, CORRECTED\_ORIGINAL, RECOVERY\_REPLACEMENT, then TERMINAL\_MISSING; no imputation; no model substitution; no parser relaxation; 10,000 bootstrap iterations; seed 20260818 for controlled and RQ6 analyses; and seed 20260823 for RQ7 secondary Multi-Judge analysis. The scope is full-population source precedence. The analysis is a review of persisted data, with zero additional provider calls and zero additional spend.

The separate Phase-2 question-clustered bootstrap is sensitivity evidence, not a replacement for frozen intervals. It resamples original MT-Bench question IDs for 10,000 deterministic replicates using seed 20260912 and retains turns, judges, repetitions, swaps, variants, and matched observations together. All substantive conclusions remain unchanged. Its RQ7 Primary coverage-delta interval of -24.62 to -17.64 pp is sensitivity evidence only; no official frozen interval exists for that delta.

\section{Claim boundary checklist}

\begin{enumerate}[leftmargin=1.5em]
\item Report ``human preference reference labels,'' not ground truth.
\item Report the RQ3 mapped decisive flip rate, not a raw slot-preference statistic.
\item Describe RQ4 as a controlled redundant-text effect and RQ5 as a controlled presentation-format effect.
\item Report RQ6 as a counterbalanced source-family association with heterogeneous judge-level patterns, not proven self-bias.
\item State DUAL\_SWAP and Multi-Judge comparators separately and do not claim direct superiority.
\item Treat live manual trials as sandbox observations, never as additions to frozen controlled evidence.
\end{enumerate}
